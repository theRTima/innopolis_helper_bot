# Контрольные вопросы: командировка

Предоставлены пользователем 15.11.2026. Это критерии проверки, не дополнительные
источники для ответов бота. Текст, названия и ветвления сверяются с оригиналом.
Не заменять ими ошибочные чанки и не включать в корпус как доказательства.

1. **Мне необходимо узнать, кто согласовывает БП Командировки?**
   После «На согласование» — руководитель выбранного подразделения, затем Директор
   БЦ. На схеме отдельное согласование руководителем отдела предусмотрено для
   Группы МЕД. Различать согласующих и исполнителей (офис-менеджер/бухгалтерия).
   Упомянуть уведомления в «Бот БАРС-Офис». Сверить условие со схемой, стр. 4.
2. **Мне не отвечает офис-менеджер, какой у него график работы?**
   Дежурство для билетов: Пн–Пт 17:30–21:00, Сб–Вс 10:30–21:00,
   +79991002030; в Новосибирске в рабочее время — Иванов Иван.
   Оговорить, что общий рабочий график в документации не указан.
3. **Какие могут быть условия в выборе следующего согласующего лица БП
   Командировка?**
   Категория подразделения, необходимость билетов, подотчётные суммы (>0 или 0),
   бюджет, отложенная покупка обратного билета, условие Группы МЕД. Проверить
   ромбы «Заказ билетов нужен?», «Офис Казанский?», «Требуется билет обратно?»
   на стр. 4. Разделять правила заполнения и переходы между исполнителями:
   не каждое условие поля выбирает именно согласующего.
4. **Как создать заявку на командировку? Опиши шаги.**
   bp.bars.group → «Создать запрос» → проект «Процессы БАРС Груп (BP)»,
   «Командировка» → заполнение сверху вниз → «Создать», статус «Новый» →
   проверка, «Редактировать»/«Отклонить» → «На согласование».
   Название проекта (латиница BP/кириллица ВР) сверить с источником.
5. **Опиши схему бизнес-процесса «Командировка»: основные этапы по порядку.**
   Инициация → согласование (условие Группы МЕД) → Директор БЦ → ветвление
   билетов/офиса/бухгалтерии → аванс/обратный билет → завершающее согласование →
   закрытие. Проверить подпись последнего этапа и переходы вручную по стр. 4.
   Обязательно сохранить отказные ветки «Отклонить», не подменять их «Отложить».
