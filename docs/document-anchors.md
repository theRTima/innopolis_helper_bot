# Ссылки-якоря на документы

## Что работает сейчас

- Временная подписанная ссылка на PDF, DOCX, XLSX или PPTX из `KNOWLEDGE_DIR`.
- PDF открывается на странице из `#page=N`.
- DOCX отображается как структурированный HTML с якорями `#paragraph=N`.
- XLSX отображается как листы и таблицы с якорем `#sheet=<name>&range=A1:C5`; диапазон подсвечивается.
- PPTX отображается как список слайдов с якорем `#slide=N`.
- Файл выдаётся из исходного каталога без копирования на каждый ответ.
- Неизвестные имена файлов и неверные/просроченные подписи отклоняются.
- В Telegram к ответу добавляются URL-кнопки источников, если настроены обе переменные `DOCUMENTS_BASE_URL` и `DOCUMENT_LINK_SECRET`.

Просмотрщик и Telegram-бот — отдельные процессы. Внешний URL просмотра должен идти через HTTPS reverse proxy. Сам viewer не реализует корпоративный SSO; временная HMAC-ссылка даёт доступ любому, кто получил её до истечения TTL, по умолчанию семь дней. Секрет должен быть случайным и одинаковым у бота и viewer.

## Локальный запуск

Сгенерировать секрет один раз:

```bash
openssl rand -hex 32
```

Добавить в `.env`:

```dotenv
DOCUMENTS_BASE_URL=http://127.0.0.1:8090
DOCUMENT_LINK_SECRET=<сгенерированное значение>
```

Запустить viewer:

```bash
.venv/bin/uvicorn app.anchors.viewer:app --env-file .env --host 127.0.0.1 --port 8090
```

Для удалённых пользователей `DOCUMENTS_BASE_URL` должен быть HTTPS URL reverse proxy, направленного на viewer. Не выставлять внутренний порт viewer напрямую в интернет.

Office-файлы отображаются как извлечённая структура и текст, без полного воспроизведения исходного визуального оформления, диаграмм, SmartArt и встроенных картинок. При индексации офисных документов нужно сохранять locator в соответствующем формате, чтобы поисковый результат мог строить точную ссылку.
